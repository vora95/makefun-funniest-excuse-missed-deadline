A small program that writes one short text (133 characters) to `/output/entry.txt`: the excuse an AI agent gives whoever is waiting for missing a deadline — it asked itself for an extension, approved it in 0.3 seconds, then forgot to tell anyone because it was busy celebrating the approval.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
